# Elkana Kipruto

### Geospatial Data Engineer · Earth Observation · Spatial Data Science

I build **geospatial data systems and analytical workflows** that turn satellite, drone, LiDAR, and other spatial data into reliable information.

My work spans **Earth observation, environmental monitoring, spatial data engineering, remote sensing, and machine learning** — from raw data and processing pipelines to validation, modelling, APIs, and interactive applications.

I take a **problem first** approach and use the appropriate tools to solve it.

- 🌍 **Earth Observation** — satellite imagery, environmental monitoring, change detection, vegetation analysis
- 🛰️ **Remote Sensing** — drone imagery, LiDAR, 3D data, terrain and canopy modelling
- 🌲 **Environmental Monitoring** — forest carbon, biomass estimation, MRV, field-to-remote-sensing validation
- 📊 **Spatial Data Science** — statistical analysis, feature engineering, regression, classification, model validation
- ⚙️ **Geospatial Engineering** — scalable raster/vector processing, spatial databases, data pipelines and APIs
- 🗺️ **Spatial Applications** — dashboards, maps, spatial services and data products

## 🔬 Selected Work

### 🌿 Bamboo Biomass & LiDAR Validation

Drone LiDAR + SLAM workflow for bamboo monitoring:

**3D data → segmentation → structural metrics → field validation → biomass modelling**

Investigating how remotely sensed structure can be used to estimate biomass and where measurement uncertainty limits model performance.

### 🌍 Earth Observation Pipelines

Automated workflows using satellite and environmental datasets for **vegetation, land-cover, environmental change, rainfall and ecosystem monitoring**.

### 🚜 Drone & Precision Agriculture

Processing high-resolution drone datasets into **orthomosaics, DSMs, DTMs, CHMs, contours and canopy metrics**, with emphasis on spatial and elevation accuracy.

### 🗺️ Geospatial Applications

Building **spatial APIs, dashboards and data services** that turn complex geospatial analysis into usable products.
